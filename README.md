## 🌟 The Vision

In today's fast-paced world, productivity often comes at the cost of burnout. **WorkLife+** is designed to bridge the gap. It's not just a task manager; it's a personal growth companion that evaluates your work habits and reminds you to stay hydrated, sleep well, and take breaks.

Using **Next.js 16** and **Google Gemini AI**, the app provides a seamless, glassmorphic interface that feels alive and responsive.

---

## ⚡ Core Features

### 🧠 1. AI Wellness Coach
Powered by **Google Gemini**, the AI Coach analyzes your activity data and provides personalized "Daily Tips" to improve your work-life balance. It's like having a life coach built into your dashboard.

### 🍅 2. Immersive Focus Zones
*   **Advanced Pomodoro**: Custom focus cycles with beautiful animations.
*   **Media Integration**: Curated Lofi beats, Focus Music, and Meditation videos directly in the app.
*   **News & Trends**: Stay informed without leaving your flow with a built-in Tech & Business news feed.

### 🧘 3. Precision Wellness Tracking
*   **Hydration Tracker**: Set daily water goals and track intake.
*   **Activity Logs**: Record walking, running, and calorie data.
*   **Sleep Metrics**: Log your sleep patterns to see how they impact your productivity.

### 🎮 4. Gamified Growth
*   **XP System**: Earn experience points for completing tasks and maintaining wellness streaks.
*   **Level Up**: Rank up your profile and unlock new achievements as you master the balance.
*   **Dynamic Dashboard**: A premium UI that reflects your current status and progress in real-time.

### 🗓️ 5. Smart Organization
*   **Unified Calendar**: Manage your schedule with an elegant, custom-styled calendar.
*   **Notification Center**: Proactive alerts for reminders, level-ups, and AI recommendations.

## 🚀 Getting Started

### 1. Requirements
Ensure you have **Node.js 18+** and a **MongoDB cluster** ready.

### 2. Installation
```bash
git clone https://github.com/adarsh232805/worklife-balance-app_final.git
cd worklife-balance-app-final
npm install
```

### 3. Environment Configuration
Create a `.env.local` file and add the following keys:
```env
# Database
MONGODB_URI=your_mongodb_connection_string

# Authentication (NextAuth)
AUTH_SECRET=your_secret_key
AUTH_TRUST_HOST=true

# AI Service
GEMINI_API_KEY=your_google_gemini_key
```

### 4. Launch
```bash
npm run dev
```
